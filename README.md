## 🚀 Projects

### AsterForge — Internal Network Penetration Test


[![README](https://img.shields.io/badge/READ%20ME-009639?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Vikram-Singh-Gill/ad-pentest-report)

A black-box internal penetration test against **ASTERFORGE.LOCAL**, a simulated corporate Active Directory environment I designed and deployed myself. Starting from a single set of low-privilege credentials, I chained credential exposure, token impersonation, LSASS credential extraction, and pass-the-hash, using BloodHound to find excessive AD permissions, all the way to **Domain Admin**. Delivered as a 24-page report with technical evidence, business impact, and prioritized remediation.

### CredHunt — Linux Credential Discovery Tool

[![README](https://img.shields.io/badge/READ%20ME-009639?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Vikram-Singh-Gill/CredHunt)

A dependency-free Python tool that recursively scans Linux filesystems for exposed credentials during authorized assessments. Regex detection for passwords, API keys, secrets, AWS access keys, and private keys, plus sensitive files like `.env`, `.bash_history`, and `id_rsa`. Supports JSON export and skips virtual filesystems like `/proc` and `/sys`.
